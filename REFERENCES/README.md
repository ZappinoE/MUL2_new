# RIFERIMENTI NUMERICI MUL2_V3

QUESTA DIRECTORY CONTIENE IL CONTRATTO DI REGRESSIONE DELLA PRIMA RELEASE.

- `BASELINE_INPUTS`: COPIE DEGLI INPUT USATI PER LE ESECUZIONI;
- `GOLDEN`: OUTPUT NUMERICI PRODOTTI DALL'ESEGUIBILE AUTOREVOLE;
- `BASELINE_MANIFEST.csv`: INVENTARIO CON HASH DEL CODICE ORIGINALE;
- `REFERENCE_MANIFEST.csv`: HASH DI INPUT E OUTPUT DI RIFERIMENTO.

`103_BEAM_B4_LE_DERIVED` E' UN CASO DERIVATO DAL BEAM 101 CAMBIANDO L'ID
IN 103. `INPUT_1d_2d_3d` E' IL CASO MISTO FORNITO DALL'AUTORE E NON E'
STATO ALTERATO.

I FILE IN QUESTA DIRECTORY NON DEVONO ESSERE SOVRASCRITTI DURANTE I TEST.
OGNI ESECUZIONE DEVE USARE UNA DIRECTORY TEMPORANEA E CONFRONTARE I DATI
PRODOTTI CON QUESTI FILE.
